# Expense Tracker GUI

A lightweight **Java desktop application** for tracking daily expenses through an intuitive **Graphical User Interface (GUI)**.  
Built using **Core Java** and **Swing**, this project demonstrates object-oriented programming principles and desktop application development.

---

## ✨ Features
- Clean and user-friendly graphical interface  
- Add, view, and manage expenses  
- Lightweight and fast execution  
- Beginner-friendly Java desktop application  

---

## 🛠️ Tech Stack
- **Language:** Java  
- **GUI Framework:** Swing 
- **Build Tool:** Java Compiler (`javac`)  

---

## 📋 Prerequisites
Ensure the following are installed on your system:

- **Java Development Kit (JDK) 8 or higher**
- Java configured in the system **PATH**

Verify Java installation:
```bash
java -version
```

ExpenseTrackerGUI/

## ⚙️ Build Instructions
Clone the repository or download the source code, then navigate to the project directory.

### Compile the source file
```bash
javac ExpenseTrackerGUI.java
```

---

## ▶️ Run the Application
After successful compilation, run the application using:
```bash
java ExpenseTrackerGUI
```

---

## ❗ Troubleshooting
- Ensure the file name matches the **public class name**.
- Run commands from the directory containing `ExpenseTrackerGUI.java`.
- If packages are used, include the **package name** while running the program.
